# Brand assets

- `tamga.svg` — the Dulo tamga (the Bulgar IYI symbol) in the solid accent blue. The three
  paths are the same ones in `src/components/brand/Tamga.tsx`, `public/favicon.svg` and
  `public/icons/`. Change one, change all.
- `og.png` — 1200x630 social card, generated by the app's own `/opengraph-image` route, so it
  always matches the shipped wordmark, palette and vocabulary. Regenerate after a copy change:

  ```bash
  curl -sS http://localhost:3000/opengraph-image -o docs/brand/og.png
  ```

Palette ("Mono"), from `docs/DESIGN.md`: near-black `#09090b`, white `#fafafa`, muted `#a1a1aa`,
one accent, electric blue `#3b82f6` (text `#60a5fa`). `og.png` and the PNG app icons in `public/icons/`
were regenerated in this palette on 9 Oct 2026; the PNGs are rendered from the SVGs beside them (opaque,
no alpha), so re-render them whenever an SVG changes, and bump `CACHE_VERSION` in `public/sw.js`.
