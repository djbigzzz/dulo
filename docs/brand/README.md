# Brand assets

- `tamga.svg` — the Dulo tamga (the Bulgar IYI symbol) in Broadcast cream on the ink ground. The three
  paths are the same ones in `src/components/brand/Tamga.tsx`, `public/favicon.svg` and
  `public/icons/`. Change one, change all.
- `og.png` — 1200x630 social card, generated by the app's own `/opengraph-image` route, so it
  always matches the shipped wordmark, palette and vocabulary. Regenerate after a copy change:

  ```bash
  curl -sS http://localhost:3000/opengraph-image -o docs/brand/og.png
  ```

Palette ("Live Broadcast", 9 Oct 2026), from `docs/DESIGN.md`: ink `#0b0b0c`, cream `#f3f0e8`, muted
`#a3a199`, gold `#ffd23c` for the one primary action and "now" only (never on the mark), green `#3ad08a`
and red `#ff5d6c` for Yes / No and gain / loss. Type: Instrument Serif, Archivo, IBM Plex Mono. `og.png`
and the PNG app icons in `public/icons/` were regenerated in this palette on 9 Oct 2026; the PNGs are
rendered from the SVGs beside them (opaque, no alpha), so re-render them whenever an SVG changes, and
bump `CACHE_VERSION` in `public/sw.js`.
