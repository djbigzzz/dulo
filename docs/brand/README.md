# Brand assets

- `tamga.svg` — the Dulo tamga (the Bulgar IYI symbol) in the gold-to-ember gradient. The three
  paths are the same ones in `src/components/brand/Tamga.tsx`, `public/favicon.svg` and
  `public/icons/`. Change one, change all.
- `og.png` — 1200x630 social card, generated by the app's own `/opengraph-image` route, so it
  always matches the shipped wordmark, palette and vocabulary. Regenerate after a copy change:

  ```bash
  curl -sS http://localhost:3000/opengraph-image -o docs/brand/og.png
  ```

Palette, from `docs/DESIGN.md`: obsidian `#0a0908`, warm white `#f4f1ea`, muted `#a9a299`,
heritage gold `#d8b46a`, ember `#ff6a2a`.
